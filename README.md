# Smiles & Styles - Nail & Beauty Salon Website

Welcome to the official repository for the Smiles & Styles website! This project is a modern, stylish, and fully responsive website built with Next.js and Tailwind CSS, designed to showcase the salon's services, gallery, and contact information. It provides a beautiful online presence to attract and inform clients.

## ✨ Features

*   **Elegant & Modern UI:** A visually appealing design that reflects the salon's brand.
*   **Service Showcase:** A dedicated section to display all available nail and beauty services with descriptions and prices.
*   **Beautiful Gallery:** An interactive carousel to feature the salon's best work and interior.
*   **Client Testimonials:** Builds trust and credibility with glowing reviews from happy customers.
*   **Contact & Booking Form:** A simple and effective form for clients to send messages and inquire about appointments.
*   **Fully Responsive:** The layout seamlessly adapts to all screen sizes, from desktops to mobile phones.

## 🛠️ Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (React)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) with [ShadCN UI](https://ui.shadcn.com/) components
*   **AI/Backend:** [Genkit](https://firebase.google.com/docs/genkit)
*   **Fonts:** Google Fonts (Belleza & Alegreya)
*   **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

To get this project up and running on your local machine for development and testing purposes, follow these simple steps.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or newer) and npm installed on your system.

### Installation & Running

1.  **Clone the repository:**
    ```bash
    git clone <your-repo-url>
    cd <your-repo-name>
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

Open [http://localhost:9002](http://localhost:9002) with your browser to see the result. You can start editing the main page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.
